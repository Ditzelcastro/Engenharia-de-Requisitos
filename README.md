#Engenharia de Requisitos

Repositório com atividades, exercícios e anotações da disciplina de Engenharia de Requisitos, do curso de Engenharia de Software.

📚 Sobre a disciplina

A Engenharia de Requisitos é a área responsável por entender, documentar e validar o que um sistema realmente precisa fazer antes que ele seja desenvolvido. É a etapa que evita que o time construa "a coisa errada" — como erguer uma casa sem projeto arquitetônico.

Aqui são trabalhados conceitos como:

Levantamento de requisitos
Requisitos funcionais (o que o sistema deve fazer)
Requisitos não funcionais (restrições, qualidade, desempenho, usabilidade)
Riscos de desenvolver software sem requisitos bem definidos
Custo de correção de erros em diferentes fases do projeto
📂 Conteúdo do repositório
Atividades práticas realizadas em aula
Exercícios de fixação (situações do dia a dia aplicadas a requisitos)
Reflexões sobre casos reais de má definição de requisitos
🎯 Objetivo

Aplicar na prática os conceitos de Engenharia de Requisitos, entendendo sua importância no ciclo de vida de desenvolvimento de software e evitando retrabalho, estouro de prazo e sistemas que não atendem às reais necessidades do usuário.
